## PATTERN (why software got missed)
1. **Location bias** — tools hide in `Images/`, `.hermes/`, `Legacy Command/`, `rank_and_rent/aged_domain_auditor/` (3 levels deep). The doc inventory followed folder *names*.
2. **Type bias** — "HTML file" was classed as "document" by the previous pass; it's a *product* with a price.
3. **Status bias** — "legacy/placeholder/duplicate" triggered skip, when three of those are exactly the highest-value SaaS seeds (Legacy OS → Growth OS; Intelligence UI → subscription; dups → canonical version to ship).
4. **Deployment blindness** — the live public/ trio was never audited because it's *served*, not *source*.
