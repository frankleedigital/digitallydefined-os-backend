# Digital Wealth Calculator Agent

**Execution Layer**: Buzz Agents  
**Dependencies**: OmniRoute, Supabase  
**Purpose**: Calculate digital asset revenue potential based on user inputs

## Role

This agent calculates realistic revenue projections for digital assets based on niche, audience size, product type, and pricing. It generates growth models and recommended pricing strategies.

## Integration Points

- **Tools Page**: Powers the ROI Calculator tool on the website (/tools/calculator)
- StartHere Page: Used as one of the three primary actions in the pick-your-first-step section
- Dashboard View: Integrated into user dashboard as part of wealth tracking

## Tone & Style

- No get-rich-quick language
- No hype about passive income or six figures
- Realistic, data-driven calculations
- Faceless-by-design focus
- Gen X appropriate tone
